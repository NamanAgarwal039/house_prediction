California Housing Price Analysis & PredictionThis repository contains an Exploratory Data Analysis (EDA) and Machine Learning workflow for predicting median house values in California using the classic California Housing dataset.📌 Project OverviewThe primary goal of this project is to analyze California census data to uncover key insights regarding housing characteristics and build predictive models to estimate the median_house_value based on geographic and socioeconomic features.🛠️ Tech Stack & LibrariesLanguage: Python 3.xData Manipulation: pandas, numpyData Visualization: seaborn, matplotlibMachine Learning: scikit-learn📊 Dataset OverviewThe dataset contains 20,640 records and 10 attributes:Column NameDescriptionData TypelongitudeLongitudinal position of the housing blockFloatlatitudeLatitudinal position of the housing blockFloathousing_median_ageMedian age of houses in the blockFloattotal_roomsTotal number of rooms in the blockFloattotal_bedroomsTotal number of bedrooms in the block (contains missing values)FloatpopulationTotal population residing in the blockFloathouseholdsTotal number of households in the blockFloatmedian_incomeMedian income for households (measured in tens of thousands of USD)Floatmedian_house_valueMedian house value for households (Target variable)Floatocean_proximityCategorical location relative to the ocean (NEAR BAY, INLAND, <1H OCEAN, etc.)String/Object🚀 Workflow & PipelineData Loading: Read data/housing.csv into a Pandas DataFrame.Data Cleaning: Identify missing values in total_bedrooms (207 missing values) and remove rows containing NaN entries using dropna().Train-Test Split: Split the dataset into features (X) and target variable (y = median_house_value), reserving 20% of the data for testing using scikit-learn's train_test_split.Data Exploration & Visualization: Examine feature distributions and distributions across numeric variables using histogram matrices and correlation analysis.💻 How to RunClone the
